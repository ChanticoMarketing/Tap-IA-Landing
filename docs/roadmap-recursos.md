## 🛠️ Especificaciones Técnicas para Agentes Implementadores

Cuando un agente de IA decida implementar o actualizar uno de estos recursos, **DEBE** seguir estas directrices para mantener la consistencia estética y de código del proyecto:

### 1. Clases CSS y Estilo de Tarjetas
*   Las tarjetas de la biblioteca se encuentran en `src/pages/recursos/index.astro`.
*   Utilizar **siempre** la clase `.matte-card` para el contenedor estático de la tarjeta.
*   Asegurar un diseño **borderless** en los interactivos: bordes sutiles y tenues en hover (`hover:border-gold/30`), sin sobrecargar de colores planos de Tailwind.
*   **Tipografía:** Usar `font-serif` (`font-playfair`) para el título del recurso (`<h3>`) y `font-sans` (`font-jakarta`) para la descripción.
*   **Contraste:** La descripción debe tener la clase `text-subtle` (`#9ca3af`) y evitar opacidades inferiores al 90% para garantizar un contraste superior a **6.5:1** (Cumplimiento WCAG 2.1 AA sobre fondos oscuros).

### 2. Estructura de Metadatos y SEO Técnico
Cada vez que se añade un recurso a la vista física:
1.  **Añadir el recurso al listado de Schema Structured Data** dentro del componente `<SchemaItemList />` al inicio de la página para que los buscadores reconozcan el listado ordenado del catálogo:
    ```astro
    <SchemaItemList
        name="Recursos TAP-IA"
        description="..."
        items={[
            { name: 'Nombre Recurso 1', url: '/recursos#ancla-1' },
            { name: 'Nombre Recurso 2', url: '/recursos#ancla-2' },
        ]}
    />
    ```
2.  Garantizar que el contenedor principal de la tarjeta posea un `id` único que corresponda con el ancla de Schema (ej. `<div id="mi-recurso" class="matte-card...">`).
